================================================================================
## КОНТЕКСТ — ЗАЩО
================================================================================

Текущият модел прилага LW охлаждане директно към въздуха + отделен
soil→air flux. Това е физически грешно: в реалността LW охлажда
ПОВЪРХНОСТТА (skin), повърхността охлажда въздуха чрез сензибилен поток H,
а почвата загрява повърхността отдолу (G). Без T_skin моделът или замръзва
на T_soil (топла есенна почва), или се взривява (студена почва + фина мрежа).

Архитектурата след промяната:

        АТМОСФЕРА (T_air[0] на z~0.5m)
             ↑ H (сензибилен поток)
    ━━━━━━ T_skin ━━━━━━  ← R_net охлажда ТУК
             ↑ G (почвен флукс)
        ПОЧВА (T_soil от ICON, КОНСТАНТА през прогнозата)

## СТЪПКА 1: Нова функция seb_step() в fog_model.py

Добави СЛЕД функцията soil_heat_flux() (не я трий засега — само спри да я викаш):

```python
# ──────────────────────────────────────────────────────────────────────────────
# Surface Energy Balance (SEB) — прогностична T_skin
# Дизайн: Fable5 одит 2026-07-10. Литература: Duynkerke (1991), COBEL-ISBA.
# ──────────────────────────────────────────────────────────────────────────────

C_SKIN   = 2.0e4     # J/m²/K — топлинна инерция на повърхностния слой (~5mm вода)
C_H_BULK = 1.2e-3    # bulk аеродинамичен коефициент (КОНСТАНТА по решение)
EPS_SFC  = 0.97      # емисивност на повърхността
ALBEDO   = 0.20      # албедо (трева/асфалт микс)
LAMBDA_G = 0.5       # W/m/K — топлопроводимост към почвата
D_SOIL_G = 0.05      # m — дълбочина на почвения слой за G
U_MIN    = 0.3       # m/s — минимален вятър (free convection floor)


def seb_step(T_skin: float, T_soil: float,
             T_air0: float, qv0: float, p0: float, rho0: float,
             U0: float, lwp_col: float,
             sw_down: float, dt: float) -> tuple:
    """
    Една стъпка на Surface Energy Balance.

    Параметри
    ----------
    T_skin  : текуща температура на повърхността [K]
    T_soil  : температура на почвата от ICON [K] — КОНСТАНТА
    T_air0  : температура на въздуха на първото ниво [K]
    qv0     : специфична влажност на първото ниво [kg/kg]
    p0      : налягане на първото ниво [Pa]
    rho0    : плътност на първото ниво [kg/m³]
    U0      : скорост на вятъра на първото ниво [m/s]
    lwp_col : общ LWP на колоната [kg/m²] — за ε_a при мъгла
    sw_down : късовълнова радиация надолу [W/m²] (0 нощем)
    dt      : времева стъпка [s]

    Връща: (T_skin_new, H, E_dew)
      T_skin_new : нова температура на повърхността [K]
      H          : сензибилен поток [W/m²], положителен = повърхност → въздух
      E_dew      : поток на роса [kg/m²/s], положителен = кондензация върху повърхността
    """
    # 1. Парно налягане [hPa] за Brunt формулата
    e_Pa  = qv0 * p0 / (eps_r + qv0 * (1 - eps_r))
    e_hPa = max(e_Pa / 100.0, 0.1)

    # 2. Атмосферна емисивност: Brunt (1932); при мъгла → черно тяло
    eps_a = 0.52 + 0.065 * np.sqrt(e_hPa)
    if lwp_col > 0.005:            # мъгла над повърхността
        eps_a = 1.0
    eps_a = min(eps_a, 1.0)

    # 3. Радиационен баланс на повърхността
    LW_down = eps_a * sigma * T_air0**4
    LW_up   = EPS_SFC * sigma * T_skin**4
    R_net   = LW_down - LW_up + (1.0 - ALBEDO) * sw_down

    # 4. Сензибилен поток (положителен = от повърхността към въздуха)
    U_eff = max(U0, U_MIN)
    H = rho0 * cp * C_H_BULK * U_eff * (T_skin - T_air0)

    # 5. Почвен флукс (положителен = от почвата към повърхността)
    G = LAMBDA_G * (T_soil - T_skin) / D_SOIL_G

    # 6. Роса: кондензация върху повърхността когато T_skin < Td на въздуха
    #    E_dew = ρ·C_H·|U|·(qv0 − qv_sat(T_skin)), само положителната част
    es_skin  = sat_vapor_pressure(np.array([T_skin]))[0]
    qsat_skin = eps_r * es_skin / (p0 - es_skin)
    E_dew = rho0 * C_H_BULK * U_eff * (qv0 - qsat_skin)
    E_dew = max(E_dew, 0.0)        # само отлагане (роса), не изпарение засега
    LE    = Lv * E_dew             # латентен поток от кондензацията

    # 7. Прогностично уравнение (+LE: кондензацията ЗАГРЯВА повърхността)
    dT_skin = dt * (R_net - H + G + LE) / C_SKIN

    # Числена защита — ЕДИНСТВЕНАТА позволена: ±2K на стъпка
    dT_skin = float(np.clip(dT_skin, -2.0, 2.0))

    return T_skin + dT_skin, H, E_dew
```

ВАЖНО за знаците: в уравнението dT_skin/dt = R_net − H + G + LE:
- R_net < 0 нощем → охлажда повърхността
- H > 0 когато T_skin > T_air → топлина отива към въздуха → изважда се (−H)
- G > 0 когато T_soil > T_skin → почвата грее повърхността → добавя се (+G)
- LE > 0 при роса → освободената латентна топлина грее повърхността (+LE)

Провери, че `sigma`, `cp`, `Lv`, `eps_r`, `sat_vapor_pressure` съществуват
в fog_model.py — те са там. Ако някое име е различно, адаптирай се към
съществуващото име, НЕ дефинирай дубликат.

```python

        lwp_col = float(np.sum(ql_new * self.rho * np.gradient(self.z)))

            self.T_skin, self.T_soil,
            float(T_new[0]), float(qv_new[0]),
            float(self.p[0]), float(self.rho[0]),
            float(np.hypot(self.u[0], self.v[0])),
            lwp_col, sw_down, self.dt)

        # Обратна връзка към въздуха: H разпределен в ефективен слой 2m

        T_new[0] += (-H_sfc) * self.dt / (self.rho[0] * cp * DZ_EFF_SEB) * (-1.0)
        # ↑ внимание със знака: H>0 значи повърхност→въздух ⇒ въздухът се ЗАГРЯВА
        # Правилно: T_new[0] += H_sfc * dt / (rho·cp·dz)
        # Напиши го директно така:
        # T_new[0] += H_sfc * self.dt / (self.rho[0] * cp * DZ_EFF_SEB)

        # Роса: изважда влага от първото ниво
        qv_new[0] -= E_dew * self.dt / (self.rho[0] * DZ_EFF_SEB)
        qv_new[0] = max(qv_new[0], 1e-8)
```
